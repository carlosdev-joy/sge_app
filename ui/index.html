Pipelines

Gestão de pipelines

≡
O que é um Pipeline?
  • Um pipeline é o orquestrador de um processo de dados — define quando, como e em qual ordem os jobs são executados.
  • Cada pipeline gera automaticamente um DAG no Airflow ao ser registrado.
  • Jobs com a mesma ordem são executados em paralelo; grupos de ordens distintas são encadeados em série.
  • Use a aba Malha para visualizar todos os pipelines e suas cadeias de execução lado a lado.
Use os filtros para buscar e clique em Novo Pipeline para cadastrar.

Jobs do pipeline
Como configurar jobs:
  • Nome do job — identificador único dentro do pipeline (ex: extract_clientes).
  • Ordem — define a sequência. Mesma ordem = execução paralela. Ex: dois jobs com ordem 2 rodam simultaneamente; o de ordem 3 só inicia quando ambos terminarem.
  • Tipo — datastage, shell, python ou storedproc.
  • Comando/caminho — nome do job DataStage, script ou procedure conforme o tipo.
  • ✅ Ao editar um pipeline, os jobs já cadastrados são carregados automaticamente aqui. Tudo o que estiver nesta lista é salvo junto com o pipeline.
  • ⚠ Remover uma linha aqui não exclui o job do banco — é apenas removido desta edição. Para excluir definitivamente um job, use a tela Jobs.
Exemplo de execução paralela:
extractdatastage
→
carga_ashell
‖ paralelo
carga_bshell
→
consolidapython

Jobs

Gestão de jobs

⬡
O que é um Job?
  • Um job é a unidade mínima de trabalho dentro de um pipeline — uma extração, transformação ou carga específica.
  • Tipos disponíveis: datastage (jobs IBM DataStage), shell (scripts bash), python (scripts .py) e storedproc (procedures SQL).
  • A Ordem define a sequência: jobs com mesma ordem rodam em paralelo; ordens distintas rodam em série (fan-out → fan-in).
  • Exemplo: ordem 1 → extração; ordem 2 → carga A e carga B simultâneas; ordem 3 → consolidação.
Consulte os jobs existentes por pipeline e, se necessário, cadastre/atualize abaixo.
