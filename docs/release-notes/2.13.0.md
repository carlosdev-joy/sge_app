# 2.13.0 — Formulários de componentes no workspace

DataStage, Shell, Python, Stored Procedure e HTTP passam a usar os formulários compartilhados no Fluxo. Selecione a etapa e abra Configurar componente. A configuração expandida permite consultar conexões, escolher o banco da procedure, trocar o modo Python e editar parâmetros DataStage com tipo, origem, meses, âncora, dias, formato e prévia. Aplicar ao fluxo altera somente o rascunho local; Salvar rascunho persiste. Cancelar conserva a configuração anterior.

Defaults DataStage vêm do próprio rascunho. Campos adicionais e parâmetros protegidos são preservados; segredos não entram no formulário, prévia ou Maestro. A criação/alteração segura de segredos é da F7C. Maestro e importação contextual serão ligados ao draft nas fases seguintes. JSON avançado permanece para diagnóstico, sem substituir os controles comuns.

Configurações Python preservam campos adicionais entre modos com configuração. Voltar ao módulo legado é recusado quando exigiria descartar esses campos. Perda de posse, revisão ou identidade impede aplicar um editor antigo. Modo consulta mantém os campos desabilitados.
