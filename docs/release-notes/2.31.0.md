# 2.31.0 — Gestão e tratamento das falhas

Gestão de Falhas ganha prioridade, histórico e link exato para a execução.
Assunção/resolução usam o responsável autenticado; concorrência e alterações
obsoletas retornam409. Repetição não envia novamente a comunicação legada.
Resolver registra tratamento sem transformar FAILED em sucesso.

Deploy DEV: backup, migrations186/187, API restart e dist atualizada.
Nenhum novo pacote, variável, DAG ou restart de worker. Reaplicação idempotente.
Contrato e limites: [F12](../eoc-f12-tratamento-alertas.md).
